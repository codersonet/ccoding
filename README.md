# ccoding - NIT SIKKIM'26

This repository contains a collection of C/C++ programming practice and learning materials organized by topic and exercise type. The project is structured to make it easy to navigate between foundational concepts, algorithmic problem solving, and language-specific practice.

## Directory Overview

### 1. `algorithms/`
Contains implementations and exercises focused on common algorithmic techniques and data structures. This folder is intended for learning sorting, searching, recursion, graph theory, dynamic programming, and related problem-solving patterns.

### 2. `arrays/`
Holds programs and exercises related to arrays, including basic operations, traversal, searching, sorting, subarray problems, and array manipulation tasks. This is a core topic for beginner-to-intermediate C/C++ practice.

### 3. `basics/`
Includes introductory C/C++ programs covering fundamental language features such as variables, data types, operators, loops, conditions, functions, and input/output. This is the starting point for newcomers.

### 4. `control-structures/`
Contains examples and exercises involving decision-making and looping constructs like `if`, `else`, `switch`, `for`, `while`, and `do-while`. These programs reinforce flow control in C/C++.

### 5. `data-structures/`
Focuses on core data structures such as stacks, queues, linked lists, trees, heaps, and hash-based structures. These programs are useful for understanding how data is stored and manipulated efficiently.

### 6. `functions/`
Contains practice related to function declaration, definition, parameters, return values, scope, recursion, and modular programming. This folder helps organize reusable logic in C/C++ programs.

### 7. `loops/`
Dedicated to loop-based exercises and patterns. It includes iterative programs for multiplication tables, number patterns, summations, factorials, and repetition-based problem solving.

### 8. `patterns/`
Contains programs that print visual patterns using nested loops and control structures. These are often used to practice iteration, formatting, and logic building in C/C++.

### 9. `pointers/`
Includes exercises on pointer arithmetic, memory addresses, dynamic allocation, arrays and pointers, function pointers, and related low-level programming concepts. This folder is essential for understanding memory management in C.

### 10. `recursion/`
Contains recursive algorithms and problems such as factorial, Fibonacci, tower of Hanoi, recursion trees, and backtracking-style exercises. This folder is focused on solving problems by function self-calling.

### 11. `strings/`
Holds programs for string manipulation, character arrays, tokenization, comparison, concatenation, searching, and pattern matching. This is important for C-style strings and textual data processing.

### 12. `structures/`
Contains examples of `struct` usage, nested structures, arrays of structures, and record-like data modeling. This folder is useful for learning how to group related data into custom types.

### 13. `templates/`
Includes reusable templates, boilerplate code, or starter examples that can be copied and adapted for new C/C++ programs. This helps speed up implementation and standardize project layout.

### 14. `utils/`
Stores helper functions, shared utilities, and common code snippets used across the repository. These may include input validation helpers, formatting functions, or generic reusable logic.

## Notes

- The repository is organized around learning progression: fundamentals first, then control flow, then data structures, algorithms, and advanced topics.
- Many folders are intended as practice exercises, coding examples, or problem-solving references.
- The structure supports both self-study and classroom-style C/C++ learning.

## Suggested Learning Path

1. Start with `basics/` and `control-structures/`
2. Move to `arrays/`, `strings/`, `functions/`, and `loops/`
3. Practice `pointers/`, `structures/`, and `data-structures/`
4. Explore `algorithms/`, `recursion/`, and `patterns/`
5. Use `templates/` and `utils/` for reusable code and project scaffolding

## Repository Purpose

`ccoding` serves as a structured code practice repository for learning and improving C/C++ programming skills through organized exercises, implementations, and examples.
